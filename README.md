# 📊 Padrón Electoral 2026 - Telecentro Shapaja

Sistema de consulta para verificar si una persona está en el padrón electoral del distrito de Uchiza.

## 🎯 ¿Qué hace este sistema?

Permite buscar por **nombre o apellido** a los ciudadanos registrados en el padrón electoral 2026 para las localidades de:
- Shapaja
- Loboyacu
- Caserío 8 de Julio
- Caserío de Guantánamo

## 🚀 Cómo usarlo

1. Abre el archivo `index.html` en tu navegador
2. Escribe un nombre o apellido en el buscador
3. Los resultados aparecerán automáticamente

## 📋 Datos incluidos

- **Total de registros:** 174 ciudadanos
- **Distrito:** Uchiza
- **Localidades:** Shapaja, Loboyacu, 8 de Julio, Guantánamo
